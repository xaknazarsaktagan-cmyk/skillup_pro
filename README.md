# Skill Up — прототип платформы для обучения программированию

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере (Chrome, Edge, Firefox).
   Если что-то не работает при открытии двойным кликом, запустите локальный сервер:
   `python -m http.server 8000` в папке проекта и откройте http://localhost:8000

## Структура

js/views-career.js       — IT-тест направлений, Roadmap, Портфолио, Career Journey

## Новое: карьерный трек
- Тест «IT-бағыт» (#/direction/test) — 6 вопросов, показывает процент совпадения
  по 7 направлениям (Frontend, Backend, Mobile, Cybersecurity, Data Science, QA, DevOps).
- Roadmap (#/direction) — персональный маршрут 0 → Beginner → Junior → Middle для
  выбранного направления; шаги по курсам засчитываются автоматически, остальные
  (Git, React, Собеседование и т.д.) отмечаются вручную.
- Готовность к Junior — процент и чек-лист прямо на странице Roadmap.
- Портфолио (#/portfolio) — проекты пользователя с описанием, технологиями,
  GitHub и демо-ссылками (использует существующую форму «Опубликовать проект»).
- Career Journey (#/journey) — общий прогресс по всей цепочке: IT-тест → Направление
  → Roadmap → Курсы → Практика → Проекты → Портфолио → Собеседование → Junior.

## Где что менять
- Добавить реальный проект в витрину «Реальные проекты» (страница #/projects): массив MY_PROJECTS в js/data.js — просто добавьте объект {id, title, desc, tech, url}
- Добавить курс или урок: массив COURSES в js/data.js
- Добавить задачу: массив TASKS в js/data.js (функция + тесты в cases). В прототипе сейчас 72 задачи: по 12 на темы «Условия», «Циклы», «Строки», «Массивы», «Рекурсия» и «Функции».
- Добавить видео по теме курса: у объекта курса в js/data.js заполните поле video ссылкой https://www.youtube.com/watch?v=... — видео отображается на странице курса и открывается в новой вкладке.
- Вопросы входного теста: массив TEST в js/data.js
- IT-направления и их Roadmap: массив DIRECTIONS в js/data.js
- Вопросы теста направлений: массив DIR_Q в js/data.js
- Цвета и шрифты: переменные в начале css/style.css
- Сбросить данные: Настройки → «Сбросить данные»

## Ограничения прототипа
Все данные хранятся в браузере (localStorage). Нет сервера, базы данных, настоящей
оплаты и запуска Python/Java/SQL. Для боевой версии нужен бэкенд
(например Next.js + PostgreSQL) и серверная песочница для кода.
